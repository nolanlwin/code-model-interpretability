# Delta spec: interp-science-page-limit

## ADDED Requirements

### Requirement: Five-page main text

The Interpretability as a Science submission SHALL contain no more than five pages of main text before its references.

#### Scenario: Rebuilt submission

- **WHEN** the manuscript is compiled using the repository build
- **THEN** all main-text sections, including limitations, finish by page five and references begin on page six or later

### Requirement: Scientific content preservation

The condensed manuscript MUST retain the five-part control matrix, all headline role findings, calibrated uncertainty statements, and acknowledged limitations.

#### Scenario: Main text is condensed

- **WHEN** redundant material is shortened or removed to meet the page limit
- **THEN** the abstract, principal evidence table, control matrix, causal result, and limitations remain consistent with the committed results

## MODIFIED Requirements

None.

## REMOVED Requirements

None.
