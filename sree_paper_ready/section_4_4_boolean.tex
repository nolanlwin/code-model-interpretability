\label{sec:boolean}
For boolean-control variables we probe the syntactic \emph{occurrence type}
of each flag site---assignment, conditional use, loop use, or return
use---from mean-pooled residual activations at the flag's own tokens, on
XLCoST Python under the protocol of Section~3: problem-grouped frozen
splits, validation-selected layers, five seeds, and every probe reported
against model-free baselines on the identical occurrence sample.

\paragraph{Occurrence type is decodable at ceiling---and so is the source
line.} Across three models spanning two families and a $4.5\times$ scale
range, the probe reaches macro-F1 $0.977$--$0.989$ against a majority
baseline of $0.174$ (Table~\ref{tab:boolean-baselines}). Selectivity over a
Hewitt-style control task \citep{hewitt2019control} is positive throughout
($+0.17$ to $+0.20$), so the probe is not merely memorizing at this sample
size. However, a character $n$-gram classifier over the \emph{enclosing
source line} (variable name masked, no model involved) reaches macro-F1
$0.988$---matching or exceeding every probe. The near-invariance of the
probe across base vs.\ code-specialized pretraining ($0.977$ vs.\ $0.985$)
and across $1.5$B vs.\ $7$B scale ($0.989$) points the same way: occurrence
type is carried by local syntax that is fully present in the surface form,
and linear decodability here is not evidence that the model computes
anything beyond it. A static analyzer decides this label with $100\%$
accuracy; the interesting question is not whether the information is
present but \emph{what carries it}, which the renaming counterfactuals
isolate.

\paragraph{Renaming does not move the probe.} We re-extract activations
for five naming counterfactuals applied by scope-correct span edits with
occurrence identities preserved (Section~3), and evaluate the identical
frozen occurrence sample under each condition. Table~\ref{tab:boolean-renaming}
reports paired deltas with cluster-bootstrap $95\%$ CIs. Every interval
includes zero, including the misleading condition C5, which renames each
flag to an index-style identifier (\texttt{i}, \texttt{idx},
\texttt{pos})---the same manipulation that costs the index role
$\Delta\mathrm{F1} = -0.272$ (Section~\ref{sec:index}). Under C5 and the
neutral conditions the probe's test predictions are frequently
\emph{identical} to baseline, prediction for prediction. Boolean occurrence
type is therefore \textbf{name-invariant}: the signal survives the complete
removal, collapse, or adversarial inversion of lexical information, because
it never depended on it.

\paragraph{Placement on the dissociation axis.} The three roles now
occupy distinct, replicated positions under one corpus and one
manipulation: index collapses under misleading names
($\Delta\mathrm{F1}=-0.272$), accumulator improves ($+0.079$), and boolean
is invariant ($\Delta\mathrm{F1}\approx 0$, CIs spanning zero across
models). Combined with the baseline analysis above, the boolean case also
sharpens the interpretation of the axis itself: name-invariance alone does
not imply an abstract role representation---here the invariant signal is
local syntax, available in the enclosing line, decodable from the earliest
layers. Cross-role comparisons of probe F1 should therefore be read
jointly with surface baselines, not against majority chance alone.

A Java replication (XLCoST, same protocol) shows the same profile---probe
$0.976 \pm 0.014$ with information complete by layer~5---though its
heavily skewed class distribution (majority $0.859$; \texttt{loop\_use}
absent from the sample) leaves less headroom, and we report it as
secondary. Renaming counterfactuals for Java await the multi-language
renamer and are out of scope here.
